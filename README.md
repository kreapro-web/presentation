# KréaPro — Site de présentation

Site de l'agence web & design **KréaPro** (La Réunion). Style Tropical / Minimaliste.

Publié via **GitHub Pages** : https://kreapro-web.github.io/presentation/

## Pages

`index.html` · `a-propos.html` · `services.html` · `prix.html` · `portfolio.html` · `contact.html`
`mentions-legales.html` · `politique-confidentialite.html` · `404.html`
`projets/` — études de cas · `demos/` — démos de sites (entreprises fictives, en `noindex`)

## Développement

```sh
npm install
npm run dev     # Tailwind en mode watch
npm run build   # CSS minifié -> assets/css/style.css (à relancer après toute modif de classes)
```

`assets/css/style.css` est généré par Tailwind — ne pas l'éditer à la main.
Les documents de travail (charte, plan, argumentaire) ne sont pas dans ce dépôt.
